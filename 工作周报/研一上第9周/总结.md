# 研一 第9周 工作小结

*王瀚宇 522026320138*       *10.17-10.23*

## 一、概括

本周完成无人机仿真应用的基础框架搭建，打通 **ROS2 Humble + Gazebo Harmonic + PX4 v1.16.2 SITL + MAVROS + QGC** 的单机/多机链路，并完成单机传感器观测与多机编队保持两个场景。

同时确认 AirSim 存在适配问题（自定义场景仅限 Windows、官方停止维护），后续开发统一转向 Gazebo，AirSim 仅作为最终演示备选。

## 二、本周工作

### 2.1 环境与框架

- 环境：Ubuntu 22.04 + ROS2 Humble + Gazebo Harmonic + PX4 v1.16.2 + MAVROS + QGC。
- 项目结构：`sim/gazebo`（模型/世界/传感器配置）、`ros2_ws/src`（`single_uav_test`、`uav_formation`）、`scripts`（启动/停止/自检）、`docs`。
- PX4 以 standalone 方式连接已启动的 Gazebo，单机与多机各有一键启动脚本。

### 2.2 单机场景

- 完成 `single_uav_test`：通过 MAVROS 实时显示飞控状态、位置/姿态/速度、IMU、GPS、高度、电池及话题频率。
- 链路：Gazebo → PX4 → MAVROS + `single_uav_test` → QGC。

### 2.3 多机编队场景

- 完成 N 机仿真：N 个 PX4 实例 + N 个 MAVROS 命名空间（`/uav1…/uavN`），共享一个 Gazebo 世界。
- 编队控制：集中式 Leader-Follower，`uav1` 由 QGC 手动控制，`uav2..N` 自动切 OFFBOARD 保持队形；`fleet_monitor` 监控多机状态与编队误差。
- 端口约定：实例 i 的 offboard 为 `14540+i ↔ 14580+i`，GCS 为 `18570+i → 14550`。

### 2.4 文档与规范

- 完成 `docs/环境搭建.md` 与 `README.md`（安装、运行、通讯拓扑）。

## 三、AirSim 适配问题与 Gazebo 迁移

- **已完成**：AirSim 单机场景构建（`sim/airsim/settings.json`，PX4Multirotor + LockStep + 传感器），可完成单机起飞/悬停/降落。
- **问题**：
  1. AirSim 自定义场景依赖 Unreal Engine，实际只能在 **Windows** 上构建/烘焙；Ubuntu 22.04 只能跑官方预编译场景，无法定制实验场地。
  2. Microsoft 已于 2022 年关停并归档 AirSim，社区 fork 基本停更。
  3. PX4 集成停留在 v1.11/v1.13，与当前 PX4 v1.16.2 不兼容；Colosseum 在 22.04 还有 Vulkan 问题。
- **决策**：后续开发统一使用 Gazebo；AirSim 仅作为最终演示备选（AirSim + UE 4.27 + PX4 v1.13.3）。

2. 多机编队：`bash scripts/start_formation.sh`
3. 文档：`docs/环境搭建.md`、`README.md`
4. AirSim 单机配置：`sim/airsim/settings.json`（演示备选）
