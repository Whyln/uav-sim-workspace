# 单机投送（初步方案）

## 1. 场景描述

- **描述**：单架无人机吊挂/携带一个物件，从起降点起飞，在带载状态下飞往目标点，最后对准目标点的视觉标记完成精准降落/放置。全程由平台作为"感知—执行"中间层，汇聚并校准定位/视觉/测高/载荷数据，下发飞行与降落指令。聚焦"**运载飞行 + 降落**"两个过程，不涉及装卸调度与返航。
- **目标**：验证平台对单机定位/视觉/测高/载荷数据的汇聚、规约与校准能力，量化其对带载飞行稳定性与降落精度的收益。
- **流程**：带载起飞 → 运载飞行 → 抵近目标 → 识别标记 → 精准降落。

**可供参考的项目**：

| 项目名称 | 项目概述 | 可能的借鉴要点 |
| --- | --- | --- |
| [drone-delivery（leomichalski）](https://github.com/leomichalski/drone-delivery) | GPS + ArUco 视觉标记的自主投送与精准降落 | GPS 粗定位 + 视觉标记末端精定位的降落链路 |

## 2. 系统组成与职责

| 组成 | 要素 | 职责 |
| --- | --- | --- |
| 物理终端 | 单架四旋翼 | 吊挂物件飞行与降落 |
| 传感器 | GNSS/RTK、下视相机、激光测距/ToF、IMU、载荷状态 | 定位、视觉识别、测高、姿态、载荷状态 |
| 执行器 | 飞控（位置/速度/姿态）、投放/释放机构 | 执行飞行与降落动作 |
| 上层应用 | 航线规划、降落控制、监控 | 生成航线与降落决策 |

**平台**在系统中可能起到的作用如下：

1. 汇聚定位/视觉/测高/载荷数据，与无人机建立信道连接；
2. **对（定位、检测、测高、姿态、载荷）数据进行规约校准，提高数据质量**；
3. 上传数据/下发指令，整体数据流：传感器 → 平台 → 上层应用 → 平台 → 执行器（飞控/投放机构）。
4. **预期效果（接入平台 vs 无平台）**：在定位漂移、视觉漏检、测高不准等噪声下，接入平台可通过数据校准拦截/纠正错误数据，使落点误差更小、降落成功率更高、载荷摆动影响更小；无平台时错误数据直接进入飞控，将导致降落偏离甚至失败。

## 3. 平台数据规约规则

- **数据源清单**：GPS 定位、标记检测结果、激光高度、IMU 姿态、载荷状态、时间戳。
- **规约书写方向**：
  - **单条数据**：校验单条记录的合法性——类型/格式、量纲、取值范围、是否 NaN/Inf。例：GPS 坐标是否在任务区、高度/速度是否合理；标记检测置信度是否达标；激光高度是否在合理范围；载荷重量/姿态是否在物理范围。
  - **同一传感器数据**：校验同一传感器数据流的时序与一致性——采样频率、时间单调性、相邻帧跳变、噪声水平。例：GPS 相邻帧位置跳变是否合理；视觉检测是否连续；激光高度是否平滑无突变。
  - **同一无人机数据**：校验跨传感器的一致性——时间对齐、坐标/标定一致、物理一致性。例：GPS 位置与 IMU 姿态变化率是否一致；标记检测位姿与当前飞行位姿是否吻合；载荷摆动是否与姿态变化一致。

## 4. 噪声来源与注入

| 噪声类型 | 现实来源 / 机理 | 对数据/系统的影响 | 注入方式 |
| --- | --- | --- | --- |
| GNSS 漂移 / 失锁 | 楼宇遮挡、多径 | 定位偏移、偏航 | 定位话题加偏、模拟中断 |
| 视觉遮挡 / 误检 | 光照、模糊、遮挡 | 标记漏检/误检、降落失败 | 图像加噪/遮挡、降帧、注入误检 |
| 激光高度噪声 | 反射面干扰 | 定高不准、悬停抖动 | 高度值叠加噪声 |
| IMU 零偏 / 漂移 | 温漂、老化 | 姿态漂移 | 角速度/加速度叠加零偏 |
| 载荷摆动 | 吊挂载荷在机动时摆动 | 姿态扰动、落点偏移 | 载荷模型中施加摆动扰动 |
| 风扰 | 阵风、气流 | 悬停偏差、轨迹漂移 | Gazebo 风场插件 |

## 5. 对照设计与评估指标

- **对照设计**：A 组接入平台（数据经规约校准后进入飞控），B 组不接入平台（数据直连），可能的 C 组不接入平台但采用噪声容忍算法。噪声分「无/低/中/高」四级。
- **评估指标**（围绕平台能力组织）：
  - **数据汇聚 / 中转能力**：多源数据汇聚完整性、时间同步误差、分发时延；
  - **数据规约与校准能力**：规约校验通过率、错误数据拦截率、校准后数据质量提升（定位精度、检测置信度、测高精度）；
  - **成果精度（平台能力的最终体现）**：落点误差、降落成功率、带载飞行稳定性（载荷摆动幅度）——反映平台保障数据质量后带来的任务收益。

## 6. 风险（该方案可能的缺点）

- **吊挂载荷摆动影响稳定**：带载飞行与降落时载荷摆动会扰动姿态、放大落点误差，且摆动难以被数据校准完全消除；
- **末端视觉依赖过强**：降落最后一段完全依赖标记识别，漏检/误检即失败；
- **风扰与载荷耦合**：吊挂系统对风扰敏感，仿真中摆动动力学难以精确复现；
- **仿真与真实差距**：缆绳/载荷动力学与真实吊挂系统存在差距；
- **规约作用可能乏力**：载荷摆动等物理扰动非"数据质量问题"，平台校准对其作用有限；
- **结果可能无法体现平台能力**：若噪声主要由物理摆动而非数据误差主导，平台收益难以体现。
