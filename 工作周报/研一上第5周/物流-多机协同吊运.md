# 多机协同吊运（初步方案）

## 1. 场景描述

- **描述**：多架无人机通过缆绳共同吊运同一大型物件，在绳张力耦合下协同飞往目标点，并平稳降落/放置到指定位置。多机之间通过缆绳受力实时耦合，需保持物件水平与机间相对位姿一致。全程由平台作为"感知—执行"中间层，汇聚并校准各机定位/姿态/张力数据，下发协同飞行与降落指令。聚焦"**协同运载飞行 + 协同降落**"两个过程。
- **目标**：验证平台对多机定位/姿态/缆绳张力/载荷状态数据的汇聚、规约与校准能力，量化其对协同运输稳定性与降落精度的收益。
- **流程**：协同吊起 → 协同运载飞行 → 抵近目标 → 协同下降 → 平稳放置。

## 2. 系统组成与职责

| 组成 | 要素 | 职责 |
| --- | --- | --- |
| 物理终端 | 多架四旋翼 + 缆绳 + 载荷 | 协同吊运与降落 |
| 传感器 | 各机 GNSS/RTK、IMU、缆绳张力传感器、载荷姿态/位置 | 定位、姿态、张力、载荷状态 |
| 执行器 | 各机飞控（位置/速度/姿态） | 执行协同飞行与降落动作 |
| 上层应用 | 协同控制、轨迹规划、监控 | 生成协同飞行与降落决策 |

**平台**在系统中可能起到的作用如下：

1. 汇聚各机定位/姿态/张力/载荷数据，与每架无人机建立信道连接；
2. **对（定位、姿态、张力、载荷）数据进行规约校准，提高数据质量，并校验机间一致性**；
3. 上传数据/下发指令，整体数据流：传感器 → 平台 → 上层应用 → 平台 → 执行器（各机飞控）。
4. **预期效果（接入平台 vs 无平台）**：在各机定位漂移、张力噪声、时间不同步等噪声下，接入平台可通过数据校准拦截/纠正错误数据并校验机间一致性，使物件更水平、落点误差更小、降落成功率更高；无平台时错误数据直接进入各机飞控，将导致张力失衡、物件倾斜与失稳。

## 3. 平台数据规约规则

- **数据源清单**：各机 GPS 定位、IMU 姿态、缆绳张力、载荷位置/姿态、时间戳。
- **规约书写方向**：
  - **单条数据**：校验单条记录的合法性——类型/格式、量纲、取值范围、是否 NaN/Inf。例：各机 GPS 坐标是否在任务区；缆绳张力是否在物理范围（非负、不过载）；载荷姿态角是否在合理范围。
  - **同一传感器数据**：校验同一传感器数据流的时序与一致性——采样频率、时间单调性、相邻帧跳变、噪声水平。例：张力数据是否连续平滑、无突变；各机定位相邻帧跳变是否合理。
  - **同一无人机数据**：校验跨传感器的一致性——时间对齐、物理一致性。例：某机 IMU 姿态与 GNSS 位置变化率是否一致；该机张力与其位姿/载荷受力是否一致。
  - **整体**：校验多机/全局一致性——机间相对位姿、张力平衡、载荷水平、时间同步。例：各机是否保持安全间距、张力是否均衡（避免单机过载）、载荷是否保持水平、各机时间是否同步。

## 4. 噪声来源与注入

| 噪声类型 | 现实来源 / 机理 | 对数据/系统的影响 | 注入方式 |
| --- | --- | --- | --- |
| 缆绳张力噪声 | 传感器误差、振动 | 张力失衡、控制失稳 | 张力值叠加噪声 |
| GNSS 漂移 / 失锁 | 遮挡、多径 | 机间相对位姿偏移 | 各机定位加偏、模拟中断 |
| IMU 零偏 / 漂移 | 温漂、老化 | 姿态漂移、载荷倾斜 | 角速度/加速度叠加零偏 |
| 载荷摆动 | 机动/风引起的摆动 | 物件晃动、落点偏移 | 载荷模型施加摆动扰动 |
| 风扰 | 阵风、气流 | 协同飞行抖动、张力突变 | Gazebo 风场插件 |
| 时间不同步 | 多机时钟漂移 | 协同指令错乱 | 错开各机时间戳 |

## 5. 对照设计与评估指标

- **对照设计**：A 组接入平台（数据经规约校准后进入飞控），B 组不接入平台（数据直连），可能的 C 组不接入平台但采用噪声容忍算法。噪声分「无/低/中/高」四级。
- **评估指标**（围绕平台能力组织）：
  - **数据汇聚 / 中转能力**：多机/多传感器数据汇聚完整性、多机时间同步误差、分发时延；
  - **数据规约与校准能力**：规约校验通过率、错误数据拦截率、校准后数据质量提升（定位精度、张力一致性）；
  - **成果精度（平台能力的最终体现）**：落点误差、物件姿态稳定性（摆动/倾斜）、降落成功率、机间协同误差——反映平台保障数据质量与一致性后带来的任务收益。

## 6. 风险（该方案可能的缺点）

- **绳张力耦合控制难**：多机通过缆绳耦合，单机扰动会传导到整体，协同控制复杂度高，仿真中张力/载荷动力学难以精确建模；
- **多机一致性问题突出**：机间相对位姿、张力平衡、时间同步任一不一致都会导致物件倾斜或失稳；
- **载荷摆动难以校准**：摆动属于物理扰动，非数据质量问题，平台规约校准对其作用有限；
- **仿真建模复杂**：缆绳/载荷/多机耦合动力学建模与求解难度大，难以真实模拟；
- **结果可能无法体现平台能力**：若误差主要由物理耦合而非数据质量主导，平台收益难以分离；
- **缺少客观评价基准**：协同运输的"稳定性/一致性"缺乏统一量化标准。
