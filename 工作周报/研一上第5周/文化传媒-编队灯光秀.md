# 编队灯光秀（初步方案）

## 1. 场景描述

- **描述**：多架无人机按预设图案编队飞行，保持队形与安全间距，同步完成灯光呈现并安全降落。编队队形与安全间距完全依赖定位精度与时间同步，适合体现平台"数据校准（时间同步）+ 行为稳定"能力。真实业务对标：高巨创新/亿航/大漠大（城市灯光秀）、Skybrush（开源商用编队框架）。
- **目标**：验证平台对定位/时间同步数据的汇聚、规约与校准能力，量化其对队形保持与安全间距的收益。
- **流程**：轨迹导入 → 编队起飞 → 队形保持/切换 → 同步呈现 → 安全降落。

## 2. 系统组成与职责

| 组成 | 要素 | 职责 |
| --- | --- | --- |
| 物理终端 | 多架四旋翼（含 LED 载荷） | 编队飞行与灯光呈现 |
| 传感器 | GNSS/RTK、IMU、气压计、（室内）光流/ArUco | 定位、姿态、高度 |
| 执行器 | 飞控（队形位置/速度）、LED 灯（灯光指令） | 执行队形与灯光动作 |
| 上层应用 | 编排软件（Blender/Skybrush）、地面站监控 | 生成轨迹与监控 |

**平台**在系统中可能起到的作用如下：

1. 汇聚各机定位/姿态/状态数据，与每架无人机建立信道连接；
2. **对（定位、姿态、时间戳）数据进行规约校准，提高数据质量，并校验多机时间同步与安全间距**；
3. 上传数据/下发指令，整体数据流：传感器 → 平台 → 上层应用 → 平台 → 执行器（飞控/LED）。
4. **预期效果（接入平台 vs 无平台）**：在定位漂移、时间不同步等噪声下，接入平台可通过数据校准拦截/纠正错误数据，使队形保持误差更小、安全间距更稳、碰撞/退出率更低；无平台时错误数据直接进入飞控，将导致队形发散与动作错乱。

## 3. 平台数据规约规则

- **数据源清单**：位置、速度、姿态、RTK 质量、时间戳、电量。
- **规约书写方向**：
  - **单条数据**：校验单条记录的合法性——类型/格式、量纲、取值范围、是否 NaN/Inf。例：单机位置是否在任务空域、速度是否在范围；RTK 解状态是否有效；姿态角是否在物理范围。
  - **同一传感器数据**：校验同一传感器数据流的时序与一致性——采样频率、时间单调性、相邻帧跳变、噪声水平。例：定位相邻帧跳变是否合理；姿态是否平滑无突变；时间戳是否单调递增。
  - **同一无人机数据**：校验跨传感器的一致性——时间对齐、物理一致性。例：某机位置与 IMU 姿态变化率是否一致；气压高度与 RTK 高度是否一致。
  - **整体**：校验多机/全局一致性——多机时间同步、最小安全间距、队形与期望轨迹一致。例：各机时间是否同步、机间间距是否不小于安全值、整体队形是否符合预设图案。

## 4. 噪声来源与注入

| 噪声类型 | 现实来源 / 机理 | 对数据/系统的影响 | 注入方式 |
| --- | --- | --- | --- |
| GNSS 漂移 / 失锁 | 多径、电磁干扰、遮挡 | 队形偏移、机间间距失衡 | 定位话题加偏、模拟中断 |
| 时钟不同步 | 晶振漂移、通信抖动 | 多机动作错乱、队形发散 | 错开各机时间戳 |
| IMU 零偏 / 漂移 | 温漂、老化 | 姿态漂移、飞行不稳 | 角速度/加速度叠加零偏 |
| 风扰 | 阵风、气流扰动 | 队形抖动、轨迹漂移 | Gazebo 风场插件 |
| 通信延迟 / 乱序 | 网络抖动、丢包 | 指令滞后、数据错乱 | 话题延迟与重排 |

## 5. 对照设计与评估指标

- **对照设计**：A 组接入平台（数据经规约校准后进入飞控），B 组不接入平台（数据直连），可能的 C 组不接入平台但采用噪声容忍算法。噪声分「无/低/中/高」四级。
- **评估指标**（围绕平台能力组织）：
  - **数据汇聚 / 中转能力**：多机/多传感器数据汇聚完整性、多机时间同步误差、分发时延；
  - **数据规约与校准能力**：规约校验通过率、错误数据拦截率、校准后数据质量提升（定位精度、时间同步误差、RTK 校验通过率）；
  - **成果精度（平台能力的最终体现）**：队形保持误差、最小安全间距、碰撞/退出率——反映平台保障数据质量与一致性后带来的任务收益。

## 6. 风险（该方案可能的缺点）

- **队形对定位精度极度敏感**：微小定位误差在密集编队中会被放大，可能触发碰撞或队形发散；
- **多机时间同步要求苛刻**：同步误差稍大即导致动作错乱，且仿真中多机时钟同步难以精确建模；
- **仿真与真实差距大**：RTK 精度、多径、电磁干扰在仿真中难以真实复现；
- **多机算力/资源需求高**：每机独立飞控 + 大量机的仿真开销大；
- **结果可能无法体现平台能力**：若队形误差主要由控制/轨迹算法而非数据质量主导，平台收益难以分离；
- **规约作用可能乏力**：定位漂移属于物理/环境因素，平台校准对其纠正能力有限。
