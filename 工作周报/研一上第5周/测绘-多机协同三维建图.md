# 多机协同三维建图（初步方案）

## 1. 场景描述

- **描述**：多架无人机协同巡飞，用 3D LiDAR 采集点云，经平台汇聚、规约、校准后重建目标结构/区域的三维点云地图，并输出几何测量成果。
- **目标**：验证平台对 LiDAR/IMU/GNSS 数据的汇聚、规约与校准能力，量化其对建图精度的收益。
- **流程**：区域分配 → 协同巡飞采集 → 数据汇聚 → 规约与校准 → 三维重建 → 成果输出与精度评估。

## 2. 系统组成与职责

| 组成 | 要素 | 职责 |
| --- | --- | --- |
| 物理终端 | 多架无人机 | 巡飞采集 |
| 传感器 | 3D LiDAR、IMU、GNSS/RTK | 点云与位姿数据 |
| 执行器 | 飞控（航线/悬停/姿态/避障） | 执行采集动作 |
| 上层应用 | SLAM 建图（FAST-LIO/LIO-SAM）、点云融合与可视化 | 生成三维模型 |

**平台**在系统中可能起到的作用如下：

1. 汇聚多机点云与位姿数据，与每个无人机建立信道连接
2. **对（点云、位姿）数据进行规约校准，提高数据质量**，从而提高建图的质量
3. 上传数据/下发指令，整体数据流：传感器 → 平台 → 上层建图 → 平台 → 飞控
4. **预期效果（接入平台 vs 无平台）**：在点云噪声、位姿漂移、时间不同步等噪声下，接入平台可通过数据校准剔除离群点、纠正位姿与时间戳，使点云地图更干净、建图精度更高、SLAM 漂移更小；无平台时错误数据直接进入建图，将导致点云错层、墙体膨胀与地图重影。

## 3. 平台数据规约规则

- **数据源清单**：LiDAR 点云、IMU 位姿、GNSS 位置、时间戳。
- **规约书写方向**：
  - **单条数据**：校验单条记录的合法性——类型/格式、量纲、取值范围、是否 NaN/Inf。例：单个点云点的距离是否在 0.1–100 m、坐标是否在任务区；单个时间戳是否为有效值；单个姿态角是否在物理范围（±180°/±90°）。
  - **同一传感器数据**：校验同一传感器数据流的时序与一致性——采样频率、时间单调性、相邻帧跳变、噪声水平、丢帧。例：LiDAR 点云帧率与点密度是否达标、时间戳是否单调递增、相邻帧位姿/点云是否发生不合理的跳变。
  - **同一无人机数据**：校验跨传感器的一致性——多传感器时间对齐、坐标/标定一致、物理一致性。例：IMU 姿态与 GNSS 位置变化率是否一致、LiDAR 点云与当前位姿是否吻合（外参正确）、各传感器时间戳是否对齐。
  - **整体**：校验多机/全局一致性——多机时钟同步、坐标系统一、ID 唯一、覆盖与重叠、冲突检测。例：各机是否在同一时间基准与坐标系下、机号/话题 ID 是否唯一、多机点云覆盖是否完整、重叠区域是否一致（无错层）。

## 4. 噪声来源与注入

| 噪声类型 | 现实来源 / 机理 | 对数据/系统的影响 | 注入方式 |
| --- | --- | --- | --- |
| LiDAR 测距噪声 | 测距精度误差、反射面材质差异、多路径 | 点云散布、表面"发毛"、几何精度下降 | 点云坐标叠加高斯噪声（σ=1–5 cm） |
| 离群点 / 噪点簇 | 镜面反射、玻璃/水面、灰尘、飞鸟、强光 | 孤立噪点、墙体"厚度膨胀" | 随机插入孤立离群点或噪点簇（1–10%） |
| 丢帧 / 降频 | 传输带宽不足、视场遮挡、扫描机械抖动 | 点云稀疏、SLAM 特征不足导致退化 | 随机丢弃帧、降低扫描频率（降频 50–100%） |
| GNSS 漂移 / 失锁 | 楼宇/树冠遮挡、多径、电离层 | 全局定位偏移、点云整体错位 | 位置话题加偏、模拟短时中断（漂移 0.5–5 m，失锁 1–5 s） |
| IMU 零偏 / 漂移 | 温漂、传感器老化 | 姿态/位姿缓慢漂移、轨迹变形 | 角速度/加速度叠加零偏（0.01–0.1 rad/s） |
| 时间不同步 | 多机/多传感器时钟漂移、通信抖动 | 多源数据错位、点云与位姿不匹配 | 错开 LiDAR/IMU/GNSS 时间戳（0–50 ms） |
| 风扰 | 阵风、气流扰动 | 姿态抖动、悬停偏差、轨迹漂移 | Gazebo 风场插件（0–5 m/s 阵风） |

## 5. 对照设计与评估指标

- **对照设计**：A 组接入平台（数据经规约校准后建图）， B 组不接入平台（原始数据直接建图），可能的C组不接入平台但建图算法考虑噪声
- **评估指标**（围绕平台能力组织）：
  - **数据汇聚 / 中转能力**：多机/多传感器数据汇聚完整性（无丢失、无重复）、多机时间同步误差、数据分发时延；
  - **数据规约与校准能力**：规约校验通过率、错误数据拦截率（注入的不合理数据被丢弃/纠正/降级的比例）、校准后数据质量提升（点云噪声水平、离群剔除率）；
  - **成果精度（平台能力的最终体现）**：点云与真值 RMSE、结构厚度误差、建图完整度、定位漂移（ATE/RPE）——反映平台保障数据质量后带来的任务收益。

## 6. 风险（该方案可能的缺点）

- **难以真实模拟**：仿真中的 LiDAR/IMU/GNSS 噪声与真实环境差距较大，实验结论的可信度有限；
- **场景难以构建与复现**：多机 SLAM + 平台闭环链路复杂，难以完整跑通，复现成本高；
- **规约作用可能乏力**：若规约阈值与校准策略设计不当，校准带来的数据质量提升不明显，平台价值难以显现；
- **结果可能无法体现平台能力**：接入/不接入平台的差异不明显，或差异被算法本身的鲁棒性掩盖；
- **缺少客观评价基准**：难以客观量化"数据质量提升"与"平台贡献"；
- **收益难以归因**：平台能力与建图算法能力相互纠缠，难以分离各自贡献；
- **数据质量与成果精度因果较弱**：校准了数据但最终建图精度提升有限（瓶颈可能在传感器或算法本身，而非数据环节）；
- **合理性判定主观**：规约"合理/不合理"的阈值难以完全客观定义。
