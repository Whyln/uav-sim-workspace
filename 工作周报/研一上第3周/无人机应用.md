# 3.公共安全

为公共安全部门提供"**高效立体态势感知 + 辅助科学决策**"的空中能力——在人力难以快速覆盖或存在危险的场景中，快速获取全局画面与现场数据，降低一线人员风险、压缩响应时间。

**1. 应急救援**

- 洪涝救援：空中标注被困人员、道路情况、风险警示、救援力量部署，制作灾害现场态势图
- 森林火灾：快速标注火线、水源、作战示意图，支持火场指挥决策
- 地震/地质灾害：全局灾情采集与**应急三维建模**，辅助态势研判与救援部署
- 山岳搜救：高空搜索 + 空地协同，实时向地面搜救队下发目标信息

**2. 执法**

- 侦查取证：高空侦查与建模记录现场全局，精准还原案情
- 治安巡逻：自动化巡逻发现隐患，远程喊话警示制止
- 交通治理：快速到场、立体视角固定现场证据
- 城管巡查：自动化巡逻支撑数字化城市管理

**3. 安全生产**

- 部门监管/企业自查：对工矿、危化园区等场所巡查（搭载红外、激光、气体探测载荷）
- 事故处置：灾情评估研判，辅助化工火灾等事故救援

# 4.农业、林业

农业上作为"**精准作业与数据采集**"平台，把播种、施药、施肥与监测从"经验估"变为"处方化作业"；林业上作为"**广域监测与生态保护**"的空中手段，低成本覆盖大范围林区。

1.农业方向

- **植保作业**：全自动精准喷洒/施肥/播种，替代人工背负作业（效率高、减药、规避人药接触风险）
- **农田监测**：多光谱载荷获取长势、营养、病虫害信息，生成变量作业处方
- **作物全周期管理**：粮食作物（水稻/小麦/玉米）数字化精准管理；经济作物（棉花/柑橘/茶叶）结合三维重建与语义识别做全自主精准施药

2.林业

- **森林防火监测**：高频巡飞及时发现并定位火情，降低护林员负担与风险
- **野生动物保护**：远程监测与种群/栖息地调查，减少人为干扰
- **森林资源调查**：病虫害普查、林区执法取证、林地资源动态管理

# 5.生态环境监测

把生态环境监管从"地面抽查"升级为"**天上看、空中测、可取证**"的常态化巡查手段，覆盖水体、大气、固废、生态与自然保护区等多要素，为执法与治理提供低成本、可复现的证据链。

**作用概括**

- **水环境**：河道/湖泊巡查（排污口、黑臭水体、水华/漂浮物）、水质采样、水文测流、岸线与水政执法取证
- **大气环境**：烟囱/无组织排放源巡查、秸秆焚烧火点监测、扬尘源定位
- **固废与岸滩**：垃圾倾倒点排查、海漂垃圾监测、尾矿库与渣场巡查
- **生态保护**：自然保护地/湿地/栖息地监管、野生动物监测、生态红线内人类活动取证
